API

Existem diferentes tipos de API, cada uma com finalidades distintas: REST (Representational State Transfer): Baseada em HTTP e geralmente usa JSON para comunicação. SOAP (Simple Object Access Protocol): Utiliza XML para troca de mensagens e tem regras mais rígidas. GraphQL: Permite consultas mais flexíveis, onde o cliente especifica os dados que deseja receber. WebSockets: Mantém conexões abertas para comunicação bidirecional em tempo real. gRPC: Usa protocolo HTTP/2 e se baseia em contratos definidos com Protocol Buffers..
